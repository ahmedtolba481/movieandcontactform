# Movies and Contact Form

A small static website with two pages:

- index.html - shows popular movies from the TMDB API with poster, title and overview
- contact.html - a contact form that sends messages through EmailJS, no backend needed

## Tech

HTML, CSS, JavaScript, Bootstrap, the TMDB API and EmailJS.

## Run

Open index.html in a browser.

## Setup

The TMDB API token is in js/main.js and the EmailJS service and template IDs are in js/email.js. Replace them with your own keys to reuse the project, and never commit real API keys to a public repository.
